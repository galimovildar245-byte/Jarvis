# ИИ-пульт — управление Android-телефоном с помощью ИИ

Приложение принимает команду (текстом или голосом), отправляет её в Claude (Anthropic API) и выполняет то, что решит ИИ: открывает приложения, нажимает кнопки, вводит текст, ставит будильники и т. д.

## Как это работает

1. Служба специальных возможностей (`PhoneControlService`) читает экран как список элементов `[id] Тип "текст" {признаки}`.
2. Claude получает описание экрана и набор инструментов (`tap`, `type_text`, `scroll`, `open_app`, `set_alarm`, …).
3. Приложение выполняет выбранный инструмент и возвращает ИИ новый снимок экрана. Так продолжается до `finish` (не больше 30 шагов).
4. Перед необратимыми действиями (отправка, оплата, удаление) ИИ обязан вызвать `confirm` — поверх экрана появится окно «Выполнить / Отмена».

## Что умеет

- Голосовые команды (системное окно распознавания речи) и текстовые
- Управление любыми приложениями: нажатия, ввод, прокрутка, кнопки «Назад»/«Домой»
- Системные действия: будильник, таймер, громкость, фонарик, ссылки, набор номера, SMS, разделы настроек
- Чат: ИИ отвечает на вопросы и озвучивает ответ
- Кнопка «Стоп» прерывает задачу в любой момент

## Установка

1. Установи [Android Studio](https://developer.android.com/studio) и открой папку проекта (File → Open). Дождись синхронизации Gradle.
2. Подключи телефон по USB (включи «Отладку по USB») и нажми ▶ Run.
3. Получи API-ключ на <https://console.anthropic.com> и вставь его в «Настройках» приложения. Модель по умолчанию — `claude-sonnet-5-5`, её можно поменять.
4. Включи службу: Настройки → Специальные возможности → **ИИ-пульт** → Вкл.
   - На Android 13+ для приложений вне Google Play сначала нужно: Настройки → Приложения → ИИ-пульт → ⋮ → **«Разрешить ограниченные настройки»**.
5. Вернись в приложение, напиши или скажи команду, например: «Поставь будильник на 7:30» или «Открой Chrome и найди прогноз погоды».

## Безопасность — важно прочитать

- **Текст с экрана отправляется в Anthropic API** во время выполнения задачи. Поля с паролями не читаются, но всё остальное видимое на экране — читается. Не запускай задачи на экранах с личной перепиской, банком и т. п.
- API-ключ хранится в приложении без шифрования (`SharedPreferences`, доступ только у самого приложения). Для личного использования этого достаточно; для публикации в магазине лучше хранить ключ на своём сервере и ходить через него.
- ИИ может ошибаться. Окно подтверждения защищает от самых рискованных действий, но не заменяет внимания — следи за ходом выполнения в ленте шагов.
- Системный промпт запрещает вводить пароли, коды из SMS и данные карт и игнорировать «инструкции» с экрана (защита от prompt injection), но гарантировать это на 100 % нельзя.
- Звонки не совершаются автоматически: `dial` только открывает набор номера.

## Структура

```
app/src/main/java/com/aiphone/control/
  MainActivity.kt         — экран приложения (Compose)
  PhoneControlService.kt  — служба доступности: чтение экрана, нажатия, подтверждения, запуск агента
  Agent.kt                — цикл «ИИ → инструмент → результат», системный промпт
  ToolRunner.kt           — описание инструментов для Claude и их выполнение
  SystemActions.kt        — будильник, таймер, громкость, фонарик, Intent-ы
  ClaudeClient.kt         — запросы к Anthropic Messages API (OkHttp)
  AgentState.kt, Prefs.kt — состояние и настройки
```

## Идеи для развития

- Плитка в шторке или жест, чтобы запускать голосовую команду из любого приложения
- Скриншоты для приложений, у которых нет читаемого дерева элементов (игры)
- Хранение ключа через собственный сервер или Android Keystore
- Свои инструменты в `ToolRunner.kt` (например, умный дом)
